# Payfreight Escrow Smart Contract (Solana / Anchor)

Pametna pogodba za varno hrambo sredstev (Escrow) v transportni logistiki, zgrajena na verigi Solana z uporabo ogrodja Anchor.

## 🛠️ How to Build & Test (Za razvijalce in ocenjevalce)

Prerequisites:
- Rust v1.75+
- Solana CLI
- Anchor Framework

### Run Tests:
```bash
yarn install
anchor test
