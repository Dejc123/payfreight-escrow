Technical Architecture

A brief look under the hood of the PayFreight Escrow repository.

Smart Contracts (Solana / Anchor)

Core logic is written in Rust using the Anchor framework:

  • payfreight_escrow_eur.rs: Manages the escrow lifecycle, stablecoin token locks, and rules.
  • payfreight_settlement.rs: Handles final trade and transport settlements.
  • escrow_eur_logistics.rs: Binds e-CMR and logistical milestones directly to financial payouts.

Backend & Services

Node.js environment bridging off-chain data with the blockchain:

  • server.js & settlementService.ts: Core backend services managing triggers, APIs, and real-time status updates.
  • payfreight_test.ts: Comprehensive test suite for contract validation.
