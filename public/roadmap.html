PayFreight Protocol

Institutional B2B Escrow & Settlement Engine for European Logistics | Public MVP Roadmap

Welcome to the official public architecture specification and execution roadmap for the PayFreight Protocol. Designed to eliminate carrier non-payment risks and streamline cross-border freight settlements across 20+ European markets.

Phase 1: Core MVP & Infrastructure Active 48h Sprint

  • Domain verification & enterprise email infrastructure via Resend (`payfreight.io`).
  • Backend mailer engine with automated transactional triggers (`escrow@`, `disputes@`).
  • 45-Minute TTL anti-exploit security warning integrated into the modal UX.
  • Live mainnet transaction simulation & secure tokenized link verification.

Phase 2: Advanced Document Compliance & Multi-CMR Engine Next Up

  • Shipper Document Configuration: Shippers can define required document quantities during load creation (e.g., standard CMR count).
  • Neutral CMR Options: Optional toggle for specialized routing where secondary/neutral CMRs are generated to obscure origin/shipper identities from the end receiver.
  • Lieferschein (Delivery Note) & Pallet Slips: Optional checkboxes for mandatory proof-of-delivery notes and pallet exchange certificates (EPAL) required before payout release.
  • Carrier Multi-Upload Workflow: Dynamic interface with [+] Add Another CMR functionality allowing carriers to batch-upload up to 6+ documents securely.

Phase 3: Secure Auth, 2FA & Institutional Dashboard Post-Launch

  • Frictionless gated user environment with Social & Email login options.
  • Google Authenticator (2FA): Mandatory or optional time-based one-time password (TOTP) verification for robust account security against hackers and financial fraud.
  • Comprehensive Shipper & Carrier Dashboards (My Transports, Freight in Progress, History).
  • In-app Mutual Cancellation & Dispute / Fault Attribution mediation tools.
  • Multi-language localization expansion for key European transport corridors.
